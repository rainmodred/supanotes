## Features
- User Authentication: Login and register functionality for users
- Note Management: Create, read, update, and delete notes
- Search Functionality: Search notes by title and content
- Tag Filtering: View notes associated with specific tags
- Theme Toggle: Switch between light, dark, and system modes
